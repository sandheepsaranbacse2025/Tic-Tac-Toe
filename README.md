# Tic Tac Toe Game (C++)

## Overview
This project is a console-based Tic Tac Toe game developed in C++.  
It demonstrates fundamental programming concepts like arrays, loops, functions, and conditional logic.

## Features
- Two-player mode (Player X vs Player O)
- Dynamic game board display
- Win detection (rows, columns, diagonals)
- Draw detection
- Replay option after game ends
- Simple and interactive console interface

## Technologies Used
- Language: C++
- Concepts:
  - Arrays
  - Loops
  - Functions
  - Conditional Statements

## Project Structure
Tic Tac Toe/
 └── tictactoe.cpp

## How to Run

Compile the program:
g++ tictactoe.cpp -o game

Run the program:
./game

## Game Instructions
1. The game is played between two players.
2. Players take turns entering a number (1–9).
3. The number corresponds to a position on the board:

1 | 2 | 3
---------
4 | 5 | 6
---------
7 | 8 | 9

4. First player to align 3 symbols (X or O) wins.
5. If all positions are filled with no winner, the game ends in a draw.
